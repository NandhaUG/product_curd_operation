# Product CRUD - Spring Boot

A beginner-friendly REST CRUD project using Spring Boot, Spring Data JPA, MySQL and Lombok.

## Requirements
- JDK 17 or newer
- Maven (or use the Maven wrapper generated by your IDE)
- MySQL Server
- Postman (optional, for API testing)

## Setup
1. Create the database:
   ```sql
   CREATE DATABASE product_db;
   ```
2. Open `src/main/resources/application.properties`.
3. Change `spring.datasource.password` to your MySQL password.
4. Import this folder as a Maven project in IntelliJ IDEA or Eclipse.
5. Run `ProductCrudApplication.java`.

Hibernate creates the `products` table automatically because `ddl-auto=update` is enabled.

## API endpoints

| Method | URL | Description |
|---|---|---|
| POST | `http://localhost:8080/api/products` | Create product |
| GET | `http://localhost:8080/api/products` | Get all products |
| GET | `http://localhost:8080/api/products/1` | Get product by ID |
| PUT | `http://localhost:8080/api/products/1` | Update product |
| DELETE | `http://localhost:8080/api/products/1` | Delete product |

### Example POST / PUT JSON
```json
{
  "name": "Laptop",
  "price": 55000.0,
  "category": "Electronics",
  "quantity": 10
}
```

## Project structure
- `entity` - Product database entity
- `repository` - Spring Data JPA repository
- `service` - CRUD business logic
- `controller` - REST endpoints

Note: This is a learning example. The simple `RuntimeException` for a missing product will return a server error by default; global exception handling and validation can be added as the next learning step.
